## English

Thank you for using Base Converter.

Base Converter is a utility app for converting decimal and hexadecimal numbers, viewing binary output, and working with signed or unsigned values across common bit widths.

### Common Questions

#### What conversions are supported?

The app supports decimal to hexadecimal and hexadecimal to decimal conversion. It also displays the binary representation of the current value.

#### Does the app support signed numbers?

Yes. You can switch between signed and unsigned modes. Signed values are interpreted using two's-complement representation based on the selected bit width.

#### Which bit widths are available?

The app supports 8, 16, 32, and 64-bit widths. The minimum and maximum values shown in the app update automatically when the bit width or number mode changes.

#### Why is my input out of range?

Each bit width has a fixed valid range. For example, 8-bit unsigned values range from 0 to 255, while 8-bit signed values range from -128 to 127.

#### Does the app collect personal data?

Base Converter is designed as a simple utility. It does not require account login. If ads are displayed, ad-related behavior may be handled by the advertising SDK according to its own policies.

### Contact

For support, bug reports, or feature suggestions, please open an issue in this repository or contact the developer through the support channel listed on the App Store.

When reporting a problem, please include:

- Your iOS version
- Your device model
- The app version
- The number mode and bit width you selected
- The input value that caused the issue

## 中文

感谢使用 Base Converter。

Base Converter 是一款用于十进制、十六进制转换的工具应用，可同步查看二进制结果，并支持有符号数和无符号数解释。

### 常见问题

#### 支持哪些转换？

应用支持十进制转十六进制、十六进制转十进制，并会同步展示当前数值对应的二进制表示。

#### 是否支持有符号数？

支持。你可以在有符号数和无符号数模式之间切换。有符号数会根据当前选择的位宽按二进制补码进行解释。

#### 支持哪些位宽？

应用支持 8、16、32、64 位宽。切换位宽或有/无符号模式时，界面会自动显示当前模式下的最小值和最大值。

#### 为什么提示输入超出范围？

不同位宽有固定的有效范围。例如，8 位无符号数范围是 0 到 255，8 位有符号数范围是 -128 到 127。

#### 应用会收集个人数据吗？

Base Converter 是一款简单工具应用，不需要账号登录。如果应用展示广告，广告相关行为可能由广告 SDK 按其政策处理。

### 联系支持

反馈问题时，建议提供：

- iOS 系统版本
